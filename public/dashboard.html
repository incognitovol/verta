How VERTA gets its numbers

Each sensor has an accelerometer (senses which way is down) and a gyroscope (senses rotation). Fused together they give a clean tilt reading. Set Upright records that tilt as zero, so every value is the change from standing straight — which is why mounting angle doesn't matter, only that the sensor stays put.
